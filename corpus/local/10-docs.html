Distill API notes

This page explains the smallest useful request path for a document that contains prose, headings, and executable examples.

Fetch a document

const response = await fetch('/document');
const article = await response.json();

The response is then handed to the extraction stage. Code is kept as a code block, while explanatory prose remains ordinary text.

Handle failure

if (!response.ok) throw new Error('document unavailable');
  • Keep the source URL with every extracted reference.
  • Do not pass untrusted schemes to an operating-system handler.
