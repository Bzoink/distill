# Distill branding

Generated by [tools/make_branding.py](../../tools/make_branding.py). Edit the
shapes or the palette there and re-run it. The generated assets are committed.
Regeneration uses fontTools and `rsvg-convert`.

```sh
python3 tools/make_branding.py
```

## The mark

A page narrowing to what is worth keeping: three lines of text, each shorter
than the last, and the drop they come to. It says what the program does — run
the page, take the substance, leave the chrome — without a picture of a
browser in it.

## The files

| File | Use |
| --- | --- |
| `distill-icon.svg` | The application icon. Teal plate; reads at 16 px. |
| `distill-48.png` | The 48 px fallback installed into the Linux desktop icon theme. |
| `distill.ico` | The Windows icon for the executables, Setup, and the uninstaller. |
| `distill-icon-light.svg` | For dark surfaces, or where a light plate suits. |
| `distill-mark.svg` | The mark alone, no plate. Takes `currentColor`. |
| `distill-logo.svg` | Mark and wordmark, in colour. |
| `distill-logo-mono.svg` | The same lockup in one colour, via `currentColor`. |

The icon carries two lines rather than the mark's three: three four-unit bars
turn to mush at 16 px, which is the size an icon has to survive.

The GTK and X11 framebuffer windows use PNGs embedded in `src/app_icon.h`.
Linux desktop installations match the GTK application ID `org.distill.Reader`
with the desktop entry and the matching icon in the `hicolor` theme.

## Palette

Taken from the reader's warm theme, so the identity and the pages agree.

| | Value | In the reader |
| --- | --- | --- |
| Ink | `#171614` | `--heading-text` |
| Teal | `#165d7a` | `--link` |
| Paper | `#f4f1ea` | `--page-background` |

## The wordmark

Outlined from `external/fonts/SourceSerif4-Bold.ttf`, the face the reader
already ships, so the logo has no font dependency: an SVG that merely *names*
a font renders as whatever the viewer happens to have installed, which for a
logo is not a rendering at all.

## Rendering to PNG

```sh
rsvg-convert -w 128 -h 128 share/branding/distill-icon.svg -o distill-128.png
```
